# Icons

20×20 stroke icons, 1.7 stroke, round caps and joins. These files draw in `muted` (#5d6470) so they read on light and dark tiles; in the app use `Plaintask.icon(name)`, which draws the same paths in `currentColor`.

- `inbox`, `today`, `upcoming`, `anytime`, `someday`, `completed`, `trash`: one per list, in the Sidebar and TabBar.
- `folder`: a project. `plus`: add. `chevron`: opens a list (mobile Browse). `back`: pushed view back button on iOS. `arrow-back`: the same on Android. `trash`: Move to Trash on a row, and the Trash list. `restore`: Restore in Trash.
- `repeat`: repeating task, in the task meta line. `close`, `search`, `tick` (the checkbox and empty-state mark).
