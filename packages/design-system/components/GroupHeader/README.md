# GroupHeader
Splits a dated list by day: Upcoming, Completed and Trash group their rows under one header per day.

- Label is the relative day ("Tomorrow", "Tue"); `note` is the date ("Tue 25 Nov") in `muted`.
- 12.5px/600 `ink`; 16px above, 4px below. Never sticky on desktop; the view header already names the list.
