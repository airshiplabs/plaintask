# EmptyState
What a list shows when it has no open tasks. It is a small reward, not an error.

- One line of headline and one of help, both specific to the list: Inbox "Inbox zero / New tasks you capture land here first."; Today "All clear for today / Nothing left on Today. Enjoy the evening."; Trash "Trash is empty / Tasks you delete wait here until you empty the Trash."
- The tick mark floats 4px on a 3.2s loop; it stops under reduced motion.
- `role="status"` so screen readers hear it when the last task goes.
